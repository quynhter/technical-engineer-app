# История изменений

## 0.5.3 — 2026-11-18

- Убрано дублирование линий всплывающих окон: тень под заголовком и
  собственный контур внутреннего native-диалога. Внешняя граница и
  разделители заголовка/подвала имеют одинаковую толщину 1 px.

- Усилены границы заголовков всплывающих окон в обеих темах. Общие
  padding 12 px и gap 8 px распространены на вложенные и появляющиеся
  блоки. Окно удаления оформлено общими секциями с отдельным подвалом
  и обновлением обработчика плана; динамические окна получают Astryx.
  Прокрутка ограничена содержимым окна: разделители доходят до краёв,
  заголовок и кнопки остаются видимыми. Проверены обе темы, узкий экран
  и клавиатура; frontend 15/15, Python 395 тестов (2 пропущены).

- ЖПК переведён на API v1/ProjectRecords: кабельные работы, прежние три поля,
  открытие записи, план удаления и добавление с work_type=cable. Формы
  кабельной линии сохранены; старое подключение входного контроля удалено
  после отдельного подтверждения, без изменения legacy-теста.
- Входной контроль/ЖВК переведены на API v1/ProjectRecords; сохранены шесть
  полей, нули, статусы, формы дня/ресурсов и план удаления. Совместимые
  HTML-функции остаются для неизменённого legacy-теста и не используются UI.
- Исправлена видимость действий записи в сохранённых формах наблюдателя:
  кнопки скрыты и отключены с учётом стилей Astryx, поля остаются читаемыми.
  При смене роли исходные свойства и стили восстанавливаются; собственный
  профиль и действия просмотра доступны. Старый список фактов удалён по
  отдельному подтверждению.
- Продолжен этап 2: факт монтажа переведён на API v1/ProjectRecords.
  Сохранены даты, статусы, нули/неизвестные количества, связанная работа,
  выбор ресурса и штатные формы. Старый код ресурсов удалён после согласования.
- В новых реестре, схемах и основных документах сохранены выделение строк,
  экспорт выбранного CSV и снятие выбора. Количественные суммы возвращены
  в общий подвал; порядковые номера исключены из сумм. Проверено отсутствие
  записи в деловую БД при просмотре, экспорте CSV и отмене окон фактов.
- База знаний проверена по полному манифесту без расхождений. Для UI после
  сброса среды создана новая временная БД; рабочие данные не затрагивались.
  Этап 2 ещё не закрыт.

- Этап 2, ресурсы: спецификация переведена на API v1/Astryx с сохранением
  десяти полей, импорта в очередь, карточки, добавления и плана удаления.
  Правило installedValue перенесено в общий модуль без сложения итогов и
  расхода; ноль и неизвестное количество различаются. Настройки таблиц
  разделены по роли, при смене контекста табличное состояние пересоздаётся.
  Старый список основных документов удалён после явного подтверждения.
- Этап 2, основные документы: список активных актов переведён на API v1 и
  Astryx ProjectRecords. Сохранены номер, название формы, дата, статус,
  создание, загрузка, карточка редактора/просмотр наблюдателя и план удаления.
  Навигационные JS-тесты переноса обновлены; старый список схем удалён после
  отдельного подтверждения пользователя.
- Этап 2, схемы: список переведён на ProjectRecords/BrowseTable Astryx с API v1;
  добавление, карточка и план удаления сохраняют штатные формы и проверки.
  При дополнительной сверке общего enhanceRowDeletion восстановлены неявные
  кнопки удаления строк в новом реестре и списке исходных файлов. Добавлены
  проверки сопоставления сущностей; просмотр журналов не получает удаление.
- Этап 2, исходные файлы: список и загрузка переведены на React/Astryx и API v1.
  Сохранены типы, несколько файлов, drag-and-drop, лимит 32 МБ, общий табличный
  инструментарий, карточка оригинала и файловая проверка. Ошибка частичной
  загрузки обновляет уже сохранённые строки без повтора записи. Старые
  обработчики удалены после отдельного подтверждения пользователя.
- Этап 2, первый раздел: React-реестр Astryx 0.7.15 подключён к навигации
  и API v1. Сохранены переходы в карточки, оригиналы, схемы, выпуски и журналы,
  поиск/фильтр/настройки/ширина/пагинация и экспорты. Исправлен приоритет явно
  заданного имени ZIP над Content-Disposition. Инвентарь старого UI и результаты
  браузерных сценариев обеих тем записаны в db/work. Рабочая БД не затронута;
  старый код реестра удалён после явного подтверждения пользователя. Этап не закрыт.
- Этап 2 начат по выбору пользователя: один общий сервер, FastAPI, SQLite WAL.
  Добавлена кнопка «Экспорт ZIP» рядом с DOCX в реестре; используется прежняя
  проверенная сборка без нового выпуска документов. Подготовлены /api/v1,
  совместимость маршрутов, SSE и постоянные хешированные сеансы в accounts.sqlite3.
  WAL включается при явной подготовке, не при чтении. На временных файлах прошли
  9 ASGI/сеансовых проверок, 25 HTTP/восстановления/запуска и два frontend-файла.
  Этап ещё не закрыт: перенос UI на Astryx по разделам и итоговые проверки впереди.
  Обновлены docs/team-service-prompt.md и короткий db/work/etap2-context.md.
  Со слов пользователя подтверждены пустая карточка и её явное создание;
  восстановление проверено автоматизированно, ручная проверка остаётся открытой.

- Этап 1: после успешного допуска девять утверждённых контрактных пунктов

## 0.5.2 — 2026-11-17

- Для наблюдателя «Основные документы» открывают «Просмотр документа» без форм редактирования, подтверждения утверждений и выпуска DOCX. Таблицы документа сохраняют объединённые заголовки бланка, пустую структуру и горизонтальную прокрутку; общие обработчики списков не добавляют к ним лишние колонки.
- Исправлены фокус после добавления текстовой строки таблицы, потеря значения при переключении связанного поля на ручной ввод (включая даты), требование даты для незаполненного необязательного подписанта и сохранение блокировки полей после смены роли наблюдателя на редактора. Добавлены DOM-проверки сценариев и HTTP-проверка чтения наблюдателем без изменений деловой БД.
- Проверка: сборка интерфейса, 18 frontend-тестов и 355 Python-тестов (2 пропущены). HTTP-сценарий подтверждает отсутствие изменений деловой БД при просмотре и запрет записи для наблюдателя. Визуальная проверка ограничена недоступностью браузера в этой ветке; рабочий сервер не перезапускался.

- Исправлены кнопки функций полей: читаемый SVG-значок ƒ и возврат к текстовому полю повторным нажатием без выбора источника с сохранением введённого значения. Убрана лишняя высота оболочки текстовых полей, чтобы уголок изменения размера совпадал с нижним краем. Таблицы исходных документов сохраняют ширину колонок и прокручиваются горизонтально, кнопки остаются внутри своих ячеек.

### Изменения от 2026-11-16

- В окне документа добавлены «Обновить на диске» (обновляет связи последнего неподписанного черновика из БД; исторические и подписанные версии пересоздаёт по снимку; старый выпуск остаётся в истории) и «Удалить версию». Единственную версию удалить нельзя; оставшиеся перенумеровываются, при удалении последней восстанавливается предыдущая карточка. Скачивание готового файла больше не создаёт лишние версии.
- После всех выбранных подписей, независимо от порядка, появляется раздел «Подписанный документ» с обязательной загрузкой через общую область drag’n’drop. Подписанный оригинал сохраняется отдельно от DOCX и исходного бланка, с проверкой принадлежности разделу и хеша. Добавлена миграция 022; прежние подписанные документы остаются доступными.
- Раздел «Связи» заменён кнопкой f рядом с полями документа и ячейками ручных таблиц: поиск по таблице, записи и полю, подтверждение вторым нажатием, возможность ручного ввода. Источники ограничены текущим объектом/разделом; существующие связи, роли и форматы дат сохраняются. Явный выбор больше не перекрывается автоматическими значениями по умолчанию. Обновлена MAP.md.
- Проверка изменений документов: 354 Python-теста (2 пропущены), 10 frontend-тестов, сборка интерфейса и аудит 91 формы без ошибок. DOM-сценарии охватывают обе темы, порядок подписания, сохранение прежних связей и функции ячеек. Визуальная проверка в браузере недоступна в этой ветке. Рабочая БД и действующий сервер не изменялись.

- Кнопка «Все объекты» получила иконку. Боковое меню сворачивается до иконок при уменьшении ширины и сохраняет размер; доступна кнопка сворачивания и клавиатурное управление. Индикатор соединения перенесён к верхнему правому краю названия «ИТД», текст доступен в подсказке и для экранного диктора. Закреплён локальный Open Sans для всех стилей оформления и добавлена предварительная загрузка шрифта.

- Добавлен `--host` в оба способа запуска веб-сервера: `0.0.0.0` открывает доступ по IPv4 в локальной сети, конкретный адрес ограничивает интерфейс. По умолчанию сохранён `127.0.0.1`. Проверки Host и Origin используют адрес принявшего соединение интерфейса; вход по коду и роли сохранены. В README добавлена инструкция по сетевому запуску.

## 0.5.1 — 2026-11-13

- Проверены поля и привязки всех 91 форм. Для 53 групп дат в 30 формах вместо полей «кавычка / кавычка / 20» используется одна календарная дата; день, месяц и полный год вычисляются для печати. Различаются даты договора, приказа, журнала, проверки и работ. В СП_77_А_5 даты начала и окончания монтажа читаются из СМР текущего раздела. Сохранены прежние отдельные значения и ручные уточнения; лишнее «20» перед полным годом удаляется при генерации.
- До трёх иных лиц, выбранных в версии документа из участников строительства, печатаются в конце с должностью, организацией, ФИО, основанием полномочий и местом для подписи. Блок наследует сетку и оформление подписантов конкретного бланка: отдельно поддержаны варианты приложенных СП_77_А_3, СП_77_А_5 и АОСР; у форм с общей таблицей копируются только строки подписи. Для подписанного акта используются сохранённые подписанты.
- Проверка исправлений: 342 Python-теста, два пропущены; frontend проходит, включая календарный ввод и фокус в обеих темах. Аудит 91 формы без ошибок; все 91 DOCX дополнительно сгенерированы с тремя иными лицами. Визуальная проверка новых блоков пока не завершена: комплектный LibreOffice не запускается из-за отсутствия версии CURL_OPENSSL_4 в libcurl. Рабочая БД и архивные документы не изменялись.

## 0.5.0 — 2026-11-13

- Веб-интерфейс переведён на локально собранный Astryx 0.7.15: AppShell, навигация, вкладки, поля, кнопки, карточки, уведомления и диалоги. Node.js нужен только для пересборки; библиотека и лицензии включены в поставку.
- Доступны пять стилей: Neutral, Stone, Butter, Gothic и Y2K. Во всех используется Open Sans. Matcha удалён; сохранённый выбор Matcha заменяется на Neutral. Двухцветная иконка здания в шапке адаптируется к стилю и светлой/тёмной теме.
- Общее дерево React с порталами сохраняет тему при переходах и закрытии окон. Восстановлены рамки полей и карточек, прокрутка длинных диалогов, клавиатурное управление и панель сохранения.
- Единые отступы окон и панелей: padding 12 px, gap 8 px, дополнительный нижний отступ заголовков и пояснений 4 px. Общая раскладка применяется и к вложенным группам: таблицам с кнопками, реквизитам, подписантам и связанным ресурсам. Кнопка добавления организации отделена от списка общим gap.
- Общие таблицы используют Astryx Table: изменение ширины всех деловых колонок, выбор видимых столбцов, сортировка, поиск, фильтрация, пагинация и экспорт CSV. Настройки сохраняются в браузере; ширина заголовков учитывает встроенные кнопки.
