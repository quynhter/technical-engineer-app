# Знания и документация

- `knowledge/` — корпуса нормативов с оригиналами.
- `knowledge-integrity.sha256` — исходные контрольные суммы; при переносе изменены только пути.
- `skills/` — навыки ведения ИТД, разбора норм и подготовки бланков.
- `reference/` — справочные примеры для подсказок приложения.
- `docs/` — документация приложения и контрактов.
- [MAP.md](MAP.md) — карта таблиц, полей и шаблонов.

Материалы разработки и проверки находятся в [development](../development/README.md).
