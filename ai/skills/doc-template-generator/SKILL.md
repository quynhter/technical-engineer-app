# Подготовка шаблона ИТД

Сохрани исходный файл отдельно и зафиксируй его SHA-256. Установи назначение, код формы и комплект. Один код соответствует одному шаблону DOCX и одному файлу полей. Фактические даты, подписантов и деловые утверждения согласуй по сведениям объекта.

- Пользовательские DOCX загружай через раздел «Шаблоны документов». Для подстановок используй поля `{{ object }}`, пути `{{ object.name }}` и таблицы со строками по схеме `{{ resources.name }}`.
- Штатные бланки реестра, ОЖР, ЖВК и ЖПК хранятся в `app/templates`. Их определения находятся в `app/forms`.

Проверь изменения в `app/forms/catalog.json`, `app/forms` и `app/templates`. Создай черновик на тестовой БД. Сверь страницы с исходником, включая колонтитулы, объединённые ячейки, переносы, текст с длинными значениями и отсутствие необработанных тегов. Подключай форму через интерфейс или `form-register` только после проверки.
