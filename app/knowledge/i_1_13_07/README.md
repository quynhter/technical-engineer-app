# База знаний: Инструкция И 1.13-07 «По оформлению приемо-сдаточной документации по электромонтажным работам»

Навигация по разделам норматива для ИИ-агента:
- `01_general_general_forms.md` — Общие положения, правила заполнения граф («норма», «произведено», «годен»), ведомость документации (форма 1) и Акт технической готовности (форма 2).
- `02_substations_akb.md` — Требования к трансформаторам (>2500 кВА, форма 7) и аккумуляторным батареям (протокол осмотра форма 9, контрольный разряд форма 10).
- `03_wiring_cables_vl.md` — Осмотр трубной канализации (форма 11), взрывозащитные уплотнения (форма 12), приемка траншей (форма 14а), мегаомметр 2500В для кабелей (форма 15), журналы прокладки и муфт (формы 18, 19), фундаменты ВЛ и паспорт ВЛ (формы 20–23).
- `04_earthing_and_index.md` — Паспорт заземляющего устройства (форма 24) и рекомендуемая форма обложки технической документации (форма 25).
- `rules.jsonl` — Детерминированные правила (напряжения мегаомметров, пороги мощности трансформаторов, терминология) для автоконтроля ИТД.
