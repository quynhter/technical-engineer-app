# ГОСТ 13663-86 — Трубы стальные профильные.Технические требования(с изменениями № 1, 2, 3)

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/GOST/%D0%93%D0%9E%D0%A1%D0%A2%2013663-86.html). Редакция и применимость не подтверждены. 

3.2. Контроль наружных размеров проводят штангенциркулем типа ШЦ-П по ГОСТ 166, калибром-скобой по ГОСТ 18360 и ГОСТ 18365 и трубным микрометром типа МТ по ГОСТ 6507. Контроль радиуса закругления и отклонения от прямого угла в поперечном сечении проводят по нормативной документации. (Измененная редакция, Изм. N 1, 3).
