# СП 77.13330.2016 — Системы автоматизации

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP77.13330.2016.html). Редакция и применимость не подтверждены. 

6.7.21 Особые требования, предъявляемые к монтажу электропроводок:

- во взрывоопасных зонах - по ГОСТ ЕС 60079-14-2013. подраздел 9.6;

- искробезопасных цепей, включая цепи полевой шины FISCO и FNICO, -по ГОСТ ЕС 60079-14-2013. раздел 16;

- телекоммуникационных кабелей для цифровой техники (локальных сетей) - по ГОСТ Р 53246-2008. раздел 8;

- нагревательных кабелей по трубопроводам и плоскостям - по инструкциям производителей кабелей.

Разрешенные способы монтажа электропроводок приведены в ГОСТ Р 50571.5.52-2011/ МЭК 60364-5-52:2009. приложение А.
