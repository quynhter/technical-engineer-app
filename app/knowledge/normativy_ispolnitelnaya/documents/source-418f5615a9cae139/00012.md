      6.8.1 Общие требования
      6.8.1.1 Помещения, защищаемые автоматическими установками газового и аэрозольного пожа­
ротушения. должны быть по возможности герметизированы. Должны быть приняты меры по ликвида­

проходки.
      6.8.1.2 Двери помещений, защищаемых автоматическими установками объемного пожаротуше­
ния. должны быть оборудованы доводчиками, которые обеспечивают закрывание двери без участия
специалиста. При этом запорное устройство двери, при его наличии, должно обеспечивать возмож­
ность открыть дверь изнутри защищаемого помещения без ключа, когда оно закрыто на ключ с внешней
стороны помещения.

ного пожаротушения, должны соответствовать проекту.
      6.8.1.3 Пусковые элементы устройств местного пуска, при их наличии, должны быть расположены

жарных постов.
