# СП 163.1325800.2014 — Конструкции с применением гипсокартонных и гипсоволокнистых листов. Правила проектирования и монтажа.

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/%D0%A1%D0%9F%20163.1325800.2014.html). Редакция и применимость не подтверждены. 

7.2.5.13 При неровности основания свыше 20 мм для формирования ровной плоскости следует предварительно наклеивать полосы из гипсокартонных листов шириной 100 мм с помощью гипсового клея. На приклеенные полосы из гипсокартонных листов с помощью тонкого слоя гипсовой шпаклевки крепят основные листы (рисунок 15,в).
