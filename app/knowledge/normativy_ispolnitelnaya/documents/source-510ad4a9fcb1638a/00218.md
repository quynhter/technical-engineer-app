# СП 62.13330.2011 — Газораспределительные системы

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP%2062.13330.2011.html). Редакция и применимость не подтверждены. 

9.4.1 Для перемещения жидкой и паровой фаз СУГ по трубопроводам ГНС, ГНП их рекомендуется оборудовать насосами, компрессорами.

Допускается использовать энергию природного газа для слива и налива СУГ, давление насыщенных паров которых при температуре 45 °С не превышает 1,2 МПа.

(Измененная редакция, Изм. N 2).
