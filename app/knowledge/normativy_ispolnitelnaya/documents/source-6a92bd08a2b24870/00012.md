# ВСН 490-87 — Проектирование и устройство свайных фундаментов и шпунтовых ограждений в условиях реконструкции промышленных предприятий и городской застройки .

2.5. Допустимые расстояния [r] при вибропогружении свай-оболочек, свай и шпунта, удовлетворяющие требованию п. 2.3, определяют из графика на чертеже по показателю l и коэффициенту d. Показатель при вибропогружении определяется по формулам:

для шпунта l = [a]_{I}/0,5a_{o};

для свай l = [a]_{I}/0,8a_{o};

для свай-оболочек l = [a]_{I}/a_{o}.
