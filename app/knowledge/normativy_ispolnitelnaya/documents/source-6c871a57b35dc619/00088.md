# ВСН 478-86 — Производственная документация по монтажу технологического оборудования и технологических трубопроводов

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/VSN/VSN%20478-86.html). Редакция и применимость не подтверждены. 

4. Заключение по документации

Рабочая документация на строительство объекта пригодна к подготовке и производству работ по монтажу технологического оборудования и технологических трубопроводов.

Подписи по п. 2.3 ВСН.

___________

* К "специальным" относятся трубопроводы, собираемые из прямых и фасонных элементов заводского изготовления - гуммированные, футерованные всеми видами покрытий, из неметаллических материалов, а также металлические для эксплуатации при Р_{у} ³ 10 МПа (100 кгс/см^{2}), на которые передаются сборочные (аксонометрические) чертежи. Для объектов, сооружаемых на импортном оборудовании, должны быть переданы аксонометрические чертежи на все трубопроводы Д_{у} ³ 50 мм.
