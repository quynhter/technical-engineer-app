# СП 86.13330.2022 — Магистральные трубопроводы

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP%2086.13330.2022.html). Редакция и применимость не подтверждены. 

7.5.2 Для выполнения подготовительных работ по обустройству площадок складирования, временных жилых городков, производственных баз, временных подъездных, вдольтрассовых и технологических дорог, а также при выполнении основных работ на трассе с применением ИСМ (песок, песчано-гравийная смесь, щебень) необходимо провести работы по доставке ИСМ по договорам с владельцами существующих ближайших карьеров.
