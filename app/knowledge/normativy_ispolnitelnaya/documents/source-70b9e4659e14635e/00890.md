# СП 86.13330.2022 — Магистральные трубопроводы

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP%2086.13330.2022.html). Редакция и применимость не подтверждены. 

15.9.7 Планировка откосов и отсыпка слоя песчаной подготовки под крепления на берегу выше меженного уровня должна выполняться бульдозером. При этом допускаются следующие отклонения отметок песчаной подготовки:

- для железобетонных покрытий из сборных плит размером более 1,0 м - ±5 см;

- для гибких покрытий из плит и решеток с модулем размером до 1,0 м - ±10 см;

- для каменной наброски и гравийной отсыпки - ±20 см;

- для закрепленных грунтов - ±15 см.
