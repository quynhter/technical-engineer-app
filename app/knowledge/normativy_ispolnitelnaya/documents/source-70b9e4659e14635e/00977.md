# СП 86.13330.2022 — Магистральные трубопроводы

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP%2086.13330.2022.html). Редакция и применимость не подтверждены. 

16.6.8 Основание стартового котлована выполняется с учетом установки в нем технологического оборудования для ГНБЩ. Для надежного закрепления и фиксации установки для продавливания трубопровода должны применяться металлоконструкции, сборные или монолитные фундаменты. Для восприятия усилий в процессе продавливания в стартовом котловане должен быть предусмотрен упор. Геометрические размеры упора должны быть определены расчетом с учетом технических характеристик проходческой машины, площади упора, свойств грунта котлована, усилий продавливания.
