# СНиП 3.05.07-85 — Системы автоматизации

3.98. Трубные проводки считаются выдержавшими испытание, если падение давления в них не превышает значений, указанных в табл. 2.

Таблица 2

| Столбец 1 | Столбец 2 | Столбец 3 | Столбец 4 | Столбец 5 |
| --- | --- | --- | --- | --- |
| Трубные проводки | Допускаемое падение давления, % за 1 ч, для рабочих сред | ← ячейка 1:2 | ← ячейка 1:2 |  |
| ↑ ячейка 1:1 | токсичные горючие газы | прочие горючие газы | воздух и инертные газы |  |
| На давление 10-100 МПа (100-1000 кгс/см^{2}) | 0,05 | 0,1 | 0,2 |  |
| Горючих, токсичных и сжиженных газов | 0,05 | 0,1 | - |  |
