# СП 45.13330.2017 — Земляные сооружения, основания и фундаменты

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP%2045.13330.2017.html). Редакция и применимость не подтверждены. 

16.5.7 Комплект технологического оборудования, необходимый для струйной цементации грунтов, в зависимости от решаемых технических задач включает:

а) буровую установку, предназначенную для бурения лидерной скважины и перемещения в ней струйного монитора с вращением или без для формирования грунтоцементного элемента;

б) миксерную станцию, предназначенную для приготовления цементного раствора;

в) высоконапорный насос, предназначенный для подачи цементного раствора к монитору;

г) компрессор, предназначенный для подачи сжатого воздуха для создания воздушного потока (двухкомпонентной и трехкомпонентной технологий);

д) склад исходных компонентов раствора для хранения и подачи в миксерную станцию. (редакция изм. №3)
