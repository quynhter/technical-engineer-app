# ГОСТ 103-2006 — Прокат сортовой горячекатанный полосовой. Сортамент

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/GOST/gost_103-2006.doc). Редакция и применимость не подтверждены. Страница PDF 3. 

```text
      общего - ОН;

      для горячей штамповки гаек - ГШГ;

      для холодной штамповки гаек - ХШГ;

      - по точности прокатки:

      по толщине:

      повышенной - БТ1, БТ2, БТ3;

      обычной - ВТ1, ВТ2, ВТ3;

      по ширине:

      повышенной - БШ1, БШ2, БШ3;

      обычной - ВШ1, ВШ2, ВШ3;

      по длине:

      мерной - МД;

      мерной с немерной длиной - МД1*;

      кратной мерной - КД;

      кратной мерной с немерной длиной - КД1*;

      немерной - НД;

      ограниченной в пределах немерной - ОД;

      ограниченной с немерной длиной - ОД1*;

     в рулонах - РД;
     ________________
     * При поставке проката мерной с немерной длиной (МД1), кратной мерной с немерной длиной
(КД1) и ограниченной с немерной длиной (ОД1) допускается наличие проката немерной длины в
количестве не более 5% массы партии.

      - по предельным отклонениям по длине проката мерной и кратной мерной длины по группам: БД и
ВД;

      - по притуплению углов на группы: БУ и ВУ;

      - по требованию к серповидности:

      высокое - АС;
```
