Примечания.

Количество должностных лиц, требуемое для осуществления государственного строительного надзора при строительстве, реконструкции, капитальном ремонте каждого объекта капитального строительства, определяется руководителем органа государственного строительного надзора. При назначении более двух должностных лиц для осуществления государственного строительного надзора при строительстве, реконструкции, капитальном ремонте объекта капитального строительства из их числа назначается ответственное лицо (руководитель группы).

В случае назначения более двух должностных лиц для осуществления государственного строительного надзора при строительстве, реконструкции, капитальном ремонте объекта капитального строительства программа проверок разрабатывается такими лицами совместно.

Обязанности по контролю за исполнением приказа (распоряжения) возлагаются по усмотрению лица, издающего приказ (распоряжение).
