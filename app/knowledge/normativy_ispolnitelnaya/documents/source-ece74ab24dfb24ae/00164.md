# СП 71.13330.2017 — Изоляционные и отделочные покрытия (актуализированная редакция СНиП 3.04.01-87)

Источник: [Основной текст сайта](https://www.ispolnitelnaya.ru/normativdocs/SP/SP71.13330.2017.html). Редакция и применимость не подтверждены. 

5.9.1 5.9.1 Контроль качества выполнения покрытий следует проводить с учетом требований настоящего свода правил и СП 17.13330, для крыш с кровлей из металлочерепицы - с учетом требований ГОСТ Р 58739-2019 (раздел 12), для крыш с кровлей из керамической и цементно-песчаной черепицы - с учетом требований ГОСТ Р 70342-2022 (раздел 12), для крыш с водоизоляционным слоем из кровельных гибких полимерных (термопластичных и эластомерных) материалов - с учетом требований ГОСТ Р 59122-2020 (раздел 14).(редакция изм. № 3)
