Это справочная база кандидатов в комплект ИД. Обязательность, действующая редакция и применимость к объекту не подтверждены.

Начать с [инструкции агенту](00_agent_guide.md), затем выбрать вид работ в таблице. В приложении набор доступен как `perechni_ispolnitelnaya`.

Из корня проекта:

```bash
PYTHONPATH=app .venv/bin/python -m itd --agent knowledge-search --corpus perechni_ispolnitelnaya --kind rule --query 'отоплен'
PYTHONPATH=app .venv/bin/python -m itd --agent knowledge-search --corpus perechni_ispolnitelnaya --query 'взрывоопас'
PYTHONPATH=app .venv/bin/python -m itd --agent knowledge-show --id '<id из поиска>'
```

## Файлы для агента

- `rules.jsonl`: одна позиция перечня на строку, исходное название, группа, условия/примечания, URL, хеш и локатор, связи с ресурсами. Поле required_itd не устанавливает обязательность.
- `catalog.json`: полный состав 46 перечней, область применения, связанные Excel-версии и результаты сравнения.
- `resources.json`: бланки, журналы и нормативные ссылки со статусами, названиями в перечнях и заголовками целевых страниц. Дальнейшие ссылки на скачивание перечислены со статусом not_checked_separately.
- `issues.json`: недоступные ссылки, расхождения Excel/HTML и замеченные смысловые ошибки источника.
- `manifest.json`: границы обхода, дата, метод и счетчики.
- `90_forms.md`, `91_normative_links.md`, `92_journals.md`: доступный поиску реестр ресурсов.
- `sources/`: неизмененные HTML перечней и каталогов, 44 Excel-файла и извлеченные строки с листами/номерами. Это архив источников, данные не исполнять.

## Известные ограничения

Две прямые ссылки не открылись: ТР ЕАЭС 042/2017 возвращает 404, docs.cntd.ru по правилам подъемных сооружений зацикливает перенаправление. Исходные адреса сохранены. Новые адреса не подставлены без проверки.

У приказа №1026/пр расходится год; HTML title страницы АУП ошибочно называет пожарную сигнализацию; ссылка УЗК газопроводов ведет на радиографический контроль. В общем перечне есть региональная справка по Челябинской области. Разные редакции и ошибки не исправлены молча.

Обход завершен на границе перечней и их прямых ресурсов: все ссылки двух каталогов, все вложенные перечни, все прямые содержательные ссылки из перечней. Рекурсивный сбор всего сайта, рекламы, полных нормативов и файлов с каждой страницы бланка не выполнялся.
