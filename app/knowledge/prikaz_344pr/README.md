# База знаний: Приказ Минстроя России от 16.05.2023 № 344/пр (в ред. от 23.06.2025 № 369/пр)

Навигация по разделам норматива для ИИ-агента:
- `01_composition.md` — Полный состав исполнительной документации (13 пунктов Приложения № 1) и ссылки на официальные XML-схемы Минстроя.
- `02_forms_requisites.md` — Требования к заполнению 5 обязательных форм актов (Приложения № 1–5 к Составу), полный перечень подписантов и правило выноса документов в реестр (при количестве > 5).
- `03_procedure.md` — Порядок ведения ИД на бумаге и в электронном виде (Приложение № 2), виды ЭП (УКЭП/УНЭП), допустимые форматы при отсутствии XML (DOCX, PDF, IFC, LandXML) и сроки передачи/хранения.
- `rules.jsonl` — Детерминированные правила для автоматической валидации актов ИД (АОСР, АОК, АУСИТО).
