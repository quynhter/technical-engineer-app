### СП 77.13330.2016 - Приложение А (Полный реестр форм производственной и исполнительной документации)

Обязательный перечень производственной документации, оформляемой при монтаже и наладке систем автоматизации согласно Таблице А.1 СП 77.13330.2016:

| Код формы | Наименование документа | Условие обязательности оформления |
|---|---|---|
| Приложение А.1 | Акт передачи рабочей документации для производства работ по монтажу СА | До начала монтажа (штамп «К производству работ») |
| Приложение А.2 | Акт готовности объекта к производству работ по монтажу СА | При приемке строительной и технологической готовности |
| Приложение А.3 | Акт передачи технических средств автоматизации в монтаж | При передаче оборудования и материалов от заказчика |
| Приложение А.4 | Протокол входного контроля оптического кабеля (измерения затухания ОВ) | Перед монтажом ВОЛС (не менее 3 замеров) |
| Приложение А.5 | Акт окончания работ по монтажу систем автоматизации | По завершении монтажа и индивидуальных испытаний проводок (передача под ПНР) |
| Приложение А.6 | Акт освидетельствования скрытых работ | Закладные конструкции, трубы в полах/стенах/фундаментах, кабели в траншеях перед закрытием |
| Приложение А.7 | Акт испытания трубных проводок на прочность и плотность | На все смонтированные трубные проводки СА |
| Приложение А.8 | Акт испытания трубных проводок на герметичность с определением падения давления | Для трубопроводов групп А, Б(а), Б(б), вакуумных и по указанию РД |
| Приложение А.9 | Акт на обезжиривание труб, арматуры и соединений | Только для трубных проводок, заполняемых кислородом |
| Приложения А.10 - А.15 | Опись документации (А.10), Свидетельство о монтаже трубных проводок (А.11), Схема сварных швов (А.12), Журнал сварки (А.13), Заключение капиллярной дефектоскопии (А.14), Список сварщиков/сборщиков (А.15) | Составляют только для трубопроводов I-IV категорий и трубопроводов с Pу свыше 10 МПа (100 кгс/см2) |
| Приложение А.16 | Протокол измерения сопротивления изоляции | На все электрические проводки СА перед сдачей монтажа |
| Приложение А.17 | Протокол прогрева кабелей на барабанах | Только при прокладке кабелей при отрицательных температурах ниже допустимых по п. 6.7.19.1 |
| Приложение А.18 | Протокол испытаний давлением локальных разделительных уплотнений или стальных труб | Для проводок во взрывоопасных зонах классов В-I и В-Iа |
| Приложение А.19 | Документация по ВОЛС (Паспорт регенерационного участка, Паспорт муфты, Протокол измерений ОК) | При монтаже волоконно-оптических линий связи |
| Приложение А.20 | Разрешение на монтаж технических средств автоматизации | Письменное разрешение заказчика/генподрядчика перед установкой приборов |
| Приложение А.21 | Ведомость смонтированных технических средств автоматизации | Обязательное приложение к Акту окончания монтажа (А.5) и Акту консервации (А.24) |
| Приложения А.22, А.23 | Акт приемки в эксплуатацию отдельных СА (А.22) / Акт приемки СА в эксплуатацию в полном объеме (А.23) | По завершении комплексной наладки (III стадия ПНР) |
| Приложение А.24 | Акт приостановки (консервации) монтажных работ по СА | При вынужденных перерывах в работах по причинам, не зависящим от подрядчика |
