# Подготовка шаблона ИТД

Сохрани исходный файл отдельно и зафиксируй его SHA-256. Установи назначение, код формы и комплект. Один код соответствует одному шаблону DOCX и одному файлу полей. Фактические даты, подписантов и деловые утверждения согласуй по сведениям объекта.

- Для формы из приложения СП используй `python app/scripts/prepare_sp_templates.py --source-dir ПАПКА --evidence-dir db/work/template-check --code КОД`. В ПАПКЕ должны быть подпапки с именами СП. Команда обновляет шаблон, JSON полей и каталог. Для изменения зарегистрированного в рабочей БД шаблона сначала согласуй различия.
- Для титульного листа используй `python app/scripts/prepare_title_template.py --source ИСХОДНИК --output ФАЙЛ`. Описание полей и порядок проверки есть в [инструкции к титульным листам](../../app/templates/Титульники/README.md).
- Для других форм используй [контракт шаблона и полей](../../app/templates/README.md). Связывай только подтверждённые значения. Учитывай варианты ролей участников и объединения в таблицах.

Проверь изменения в `app/templates/catalog.json`, `app/forms` и `app/templates`. Создай черновик на тестовой БД. Сверь страницы с исходником, включая колонтитулы, объединённые ячейки, переносы, текст с длинными значениями и отсутствие необработанных тегов. Подключай форму через интерфейс или `form-register` только после проверки.
